# AI didn't break your knowledge system. It exposed that you never had one.

*Rizom builds living memory for hybrid human–AI teams — memory that works, from one team to an economy.*

**The science.** Organisational psychology has one finding it keeps replicating: a team's intelligence is not the sum of its members' talent. It lives in the team's *transactive memory system* — the shared, mostly invisible map of who knows what, whose judgment settles which questions, and how knowledge moves. Since Daniel Wegner named the construct in 1985, the evidence has only hardened. Kyle Lewis's validated scale (2003) measures it on three dimensions — specialization, credibility, coordination — and meta-analyses across hundreds of teams confirm that strong-memory teams consistently outperform equally talented ones. High performers score above 70% on TMS measures; most teams sit far below. The gap is structural, not personal.

**The discontinuity.** Four decades of that research studied teams of humans. Those teams no longer exist. Every team is now a hybrid team — people working alongside AI systems that read, write, remember, and act. And AI arrives with no place in the team's memory: it doesn't know who knows what, whose word is trusted, or why last year's decision was made, because none of that was ever made explicit anywhere. This is why AI rollouts underdeliver so predictably — organisations are adding members to a memory system that exists only in people's heads. **Rizom is the first to build transactive memory for hybrid human–AI teams:** the research, extended into territory the researchers never had to consider.

**The system.** What Rizom builds is living memory — shared memory as working infrastructure, not documentation. It stays alive because it feeds itself: a **Brain** captures from where work already happens — the chat where a decision lands, the email thread, the conversation — so the memory stays current without anyone maintaining a knowledge base. That is why this works where every wiki and knowledge platform has failed: those demand upkeep nobody has time for; living memory accumulates as a by-product of working. Humans and AI work from the same living memory, so both finally operate from the same map — and it is open source and self-hostable, because memory this important belongs to the organisation that creates it.

Because the memory is built from real collaboration, it can do what the research never could: measure. Forty years of science assessed transactive memory by questionnaire — self-reported, point-in-time. A brain derives a **Living Memory Score** from the work itself: continuous, behavioral, evidence all the way down. A better instrument than the science has ever had — and a number an organisation can actually move. Brains interconnect — signed, permissioned, selective — so living memory scales the way collaboration does: team, organisation, ecosystem.

**The endpoint.** Follow the arc to its end and living memory becomes an economy's coordination layer. A brain holds not just what its people know but how they work — and the same signals behind the Living Memory Score become composition logic: teams of people and agents assembled on evidence of how they actually collaborate, not resumes and keywords. An economy of collaborators, coordinating through living memory. The position underneath the vision is concrete: four decades of public research no one else has built into infrastructure, a platform that is live and open today, and a network whose value compounds with every brain that joins it.
