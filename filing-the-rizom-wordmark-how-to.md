# Filing the Rizom Wordmark — How-To

Companion to [[rizom-trademark-policy-draft]] and [[certified-partner-program-action-checklist]]. Drafted 2026-07-29. Practical guide for the BV to file the "RIZOM" word mark. Verify current fees and forms at filing time; this is a working guide, not legal advice.

## 0. Clearance search first — one known name to check

Before spending anything, search for conflicts. A registered earlier mark that is similar, for similar goods/services, can block the application via opposition.

- Search **TMview** (tmview.europa.eu) and **EUIPO eSearch** for "rizom", "rhizome", "rizome" and close variants, in classes 9, 35, 41, 42.
- **Known flag: Rizom-Lab** — a French software company (RizomUV, 3D unwrapping software). Same word, software goods. Whether it blocks depends on their registrations and the exact goods/services wording; this is the one item that genuinely warrants an hour of trademark counsel before filing, because it sits in class 9/42 territory.
- Also check national Benelux register (BOIP), company registers, and plain web search.

If the search comes back ugly in class 9, a fallback exists: lean the specification toward services (35/41/42) and the "Rizom Certified" certification context, where the conflict surface is smaller. Counsel call.

## 1. What to file

- **A word mark: "RIZOM"** — plain text, no styling. Word marks give the broadest protection (any font, any color, any presentation). File the logo separately later if it becomes distinctive; the word is what partners and forks would misuse.
- **Applicant: Rizom B.V.** — assignment to the stichting later is a simple recorded transfer (free to record online at EUIPO).

## 2. Where: EUIPO, not just Benelux

Recommendation: file an **EU trade mark (EUTM) at EUIPO** (euipo.europa.eu), not a Benelux-only BOIP filing.

| | Benelux (BOIP) | EU (EUIPO) |
|---|---|---|
| Coverage | NL/BE/LUX | all 27 EU states |
| Cost (4 classes) | ~€433 | €1,200 |
| Opposition exposure | Benelux marks only | any earlier EU/national mark |

The partner model is explicitly international (community spans Amsterdam to Taipei to SF), so Benelux-only protection undershoots the program it exists to protect. The EUTM's larger opposition surface is the price of the coverage — which is why the clearance search comes first. For non-EU partner markets later (UK, US), extend via the **Madrid Protocol** using the EUTM as base; Taiwan is not in Madrid and would need a direct national filing if it ever matters.

## 3. Classes and specification

Four Nice classes, using EUIPO harmonized terms where possible (keeps the application in the fast track):

- **Class 9** — downloadable computer software; downloadable software for knowledge management and artificial-intelligence agents.
- **Class 35** — business management consultancy; business organization consultancy.
- **Class 41** — education; providing of training; arranging and conducting of workshops.
- **Class 42** — software as a service (SaaS); design and development of computer software; hosting services.

Keep the specification honest and used: an EUTM becomes vulnerable to revocation for any goods/services not put to genuine use within 5 years. Don't pad.

## 4. Cost and mechanics

- EUIPO online filing: **€850** (first class) + **€50** (second) + **€150** (each further) = **€1,200** for four classes. Pay by card at filing.
- File online via the EUIPO "apply for a trade mark" route; the four-class word-mark application is a form most founders complete themselves in under an hour — the value of counsel is the clearance judgment (step 0), not the form.

## 5. Timeline

1. **Filing day** — this sets the priority date; everything after is process.
2. Examination (formalities + absolute grounds): ~1 month. "Rizom" is invented/distinctive, so absolute-grounds refusal is unlikely.
3. Publication, then a **3-month opposition window** — this is where a Rizom-Lab-type conflict would surface.
4. If unopposed: registration, typically **4–6 months** after filing. Valid 10 years, renewable indefinitely.

The trademark policy can publish as soon as the application is **filed** (say "trademark application pending"); don't wait for registration.

## 6. After registration

- Record the assignment BV → stichting when the stichting exists (EUIPO transfer recording, free online).
- Diarize renewal (10 years) and the 5-year use deadline per class.
- Use the mark as registered ("Rizom") in commerce — genuine use is what keeps it alive.
