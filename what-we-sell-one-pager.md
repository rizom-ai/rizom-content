# We sell the work, not the software.

*Rizom deploys and runs living memory — a Brain — for organisations. The software is open source; what you buy is a memory that works.*

**The product.** A Brain is shared memory for a hybrid human–AI team, built as working infrastructure rather than documentation. It captures from where work already happens — the chat where a decision lands, the email thread, the conversation — so it stays current without anyone maintaining a knowledge base. Humans and AI systems work from the same living memory, and a Living Memory Score tracks how well it is actually working: continuous and behavioral, derived from the work itself. The platform is open source (AGPL) and self-hostable — memory this important belongs to the organisation that creates it, so there is no lock-in to buy your way out of later.

**How an engagement works.** Three steps, each priced, each a natural stopping point:

- **Step 1 — Knowledge Session · €5,000 fixed.** Diagnose and map: individual interviews with 6–10 people (the fragility test: what does this person know that nobody else does, and what breaks when they leave?), a half-day workshop, and a written playbook of where knowledge lives, where it leaks, and what a Brain would hold. Credits in full toward a pilot build — and works as a go/no-go point for both sides.
- **Step 2 — Pilot build · €15,000 early-adopter (standard €35,000).** Install: a working Brain, deployed on your infrastructure or hosted by us, populated with one team's real memory and in daily use. Early-adopter pricing is earned, not timed — launch clients co-develop and stand as named references.
- **Step 3 — Retainer (optional) · €4,000/month early-adopter (standard €7,000).** Hosting, upgrades, and support — we run the Brain so your team just uses it. Monthly, cancellable: the exported system can always be self-hosted, so you stay because it works, not because you are stuck.

**Who this is for.** Organisations whose knowledge *is* the work — especially fields where knowledge leaves faster than it accumulates: young professional fields, high fluctuation, fast-moving practice. Current pilots run in innovation networks, sustainability, and art & academia. Organisations that want to open a whole field rather than fix one team can take the partner track instead: co-develop the first Brain application for their vertical and become the certified partner who delivers it there (see [[innovation-lead-pilot-offer-outline]]).

**The foundation underneath.** The approach is built on transactive memory systems — four decades of organisational psychology on why some teams consistently outperform equally talented ones, extended by Rizom to teams that now include AI.
