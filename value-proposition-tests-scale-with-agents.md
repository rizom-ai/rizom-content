# Value Proposition Tests: Scale with Agents

*Companion to [[beachhead-scale-with-agents]]. Tracks how the wedge statement itself lands with real prospects — separate from whether they qualify. The core open question: does "make one agent safe and effective" resonate, or do people hear something else (e.g. "you're a consultancy," "you're another AI search tool")?*

## The statement being tested

> Rizom turns scattered operating knowledge into a governed context layer, then uses it to make your first agent workflow reliable.

Shorthand used in outreach: "make one valuable agent safe and effective," not "organize your knowledge."

## What to log per test

- **Date / context:** which call or outreach message
- **Exact framing used:** if it deviated from the statement above
- **Reaction:** what they understood it to mean, in their own words if possible
- **Did it land as intended?** yes / partially / no, and what they heard instead
- **Objection raised, if any:** e.g. "sounds like consulting," "we already have a knowledge base," "how is this different from [X]"
- **Adjustment to consider:** any wording change suggested by the reaction

## Why this matters

The central risk named in [[beachhead-scale-with-agents]]: if prospects only value the agent output and not the context layer underneath, Rizom risks becoming an automation consultancy rather than a product. Watch specifically for whether prospects ask about reusing the layer for a second agent/workflow unprompted — that is the strongest organic signal the positioning is landing as a product, not a project.
