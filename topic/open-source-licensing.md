---
title: Open Source Licensing
---
The licensing strategy combines strong copyleft protection for the core runtime with permissive licensing for extension surfaces. The runtime moves from Apache to AGPL-3.0 to deter proprietary hosted forks and platform capture, while the plugin SDK, AT Protocol contracts, and theme interfaces remain Apache-licensed so partners can build and commercialize extensions. A Developer Certificate of Origin is planned for future contributions to support clean intellectual-property succession. Copyright initially remains with the BV, with a planned written transfer to a future foundation. Trademark controls separate free code from controlled brand usage by permitting descriptive references while reserving certified marks for approved partners and requiring renamed forks. Together, this structure preserves the software commons while supporting professional services, implementation, and broader commercial participation.
